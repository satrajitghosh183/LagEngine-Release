# Hello Triangle

A minimal rendering example: a single rotating triangle.

## What it demonstrates

- Basic OpenGL setup
- Shader creation and binding
- Vertex buffer and draw call
- Simple animation loop

## How to run

From the build directory:
```bash
./bin/HelloTriangle
```

## Try changing

- Modify the vertex positions in the vertex buffer.
- Change the rotation speed or axis in the update loop.
- Add a second triangle with different colors.

# Physics Demo

Rigid body physics: falling cubes and spheres with gravity and collision.

## What it demonstrates

- PhysicsWorld and RigidBody
- Box and Sphere colliders
- Spawn on spacebar
- Fixed timestep integration

## How to run

From the build directory:
```bash
./bin/PhysicsDemo
```

## Try changing

- Adjust mass, restitution, and damping on spawned bodies.
- Change gravity direction or magnitude.
- Add more obstacle shapes.

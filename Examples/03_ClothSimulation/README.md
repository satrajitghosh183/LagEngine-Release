# Cloth Simulation

XPBD-based cloth with wind, collision sphere, and UI controls.

## What it demonstrates

- SoftBodyComponent and XPBD solver
- Distance, bending, and collision constraints
- Wind forces
- Reset and pause

## How to run

```bash
./bin/ClothSimulation
```

## Try changing

- Grid resolution (Res X/Y).
- Mass, damping, compliance.
- Wind direction and strength.

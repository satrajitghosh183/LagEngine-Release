# 🎮 GameEngine

Professional 3D Game Engine built in C++17.

## Features

- 🎨 Modern 3D Renderer
- ⚡ Physics Engine (Rigid body, Soft body, Fluids)
- 🎬 Animation System
- 🎵 3D Audio
- ✨ Particle System
- 🎮 Input System
- 📝 Lua Scripting
- 🖥️ ImGui UI

## Building
```bash
mkdir build && cd build
cmake ..
cmake --build .
```

## Running Examples
```bash
./bin/PhysicsDemo
```
